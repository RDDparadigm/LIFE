
Dalla legge di annullamento del prodotto abbiamo che **ab = 0 se e solo se a = 0 V b = 0**

Possiamo utilizzare questa legge per risolvere le equazioni

Esempio con polinomi già scomposti

- (2x + 4)(x - 6) = 0
- Poniamo 2x + 4 = 0 V x - 6 = 0 se e solo se x = -2 V x = 6
- L'insieme delle soluzioni è S = {-2, 6}


Esempio con polinomi da scomporre

- x^3 - 6x^2 = 0
- Scomponiamo in fattori x^2 (x - 6) = 0
- Applichiamo la legge di annullamento del prodotto x^2 = 0 V x - 6 = 0
- Risolviamo x = 0 V x = 6
- L'insieme delle soluzioni è S = {0, 6}
