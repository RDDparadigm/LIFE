
Se abbiamo lo stesso valore ad entrambi i membri di un equazione, allora possiamo rimuoverlo direttamente


Esempio

Se a + c = b + c, allora possiamo togliere c da entrambi i membri per avere a = b

Se a * c = b * c, con c diverso da 0, allora possiamo togliere c da entrambi i membri per avere a = b
