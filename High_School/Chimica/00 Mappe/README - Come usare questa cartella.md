# README - Come usare questa cartella

Questa cartella è strutturata per usare Obsidian come sistema di studio, non come archivio di appunti lunghi.

## Come navigare
Parti da [[Mappa Chimica]]. Da lì raggiungi le mappe tematiche, le note concetto, gli esercizi e le domande d'esame.

## Regola pratica
- Le note in `01 Concetti` sono brevi, autonome e ripassabili.
- Le note in `02 Esercizi` collegano la pratica alla teoria.
- Le note in `03 Domande esame` servono per il recupero attivo.
- Le note in `00 Mappe` sono le pagine indice: usale come punto di partenza.

## Workflow consigliato
1. Parti dalla mappa dell'argomento.
2. Studia una nota concetto alla volta.
3. Prova a rispondere alle domande d'esame senza guardare gli appunti.
4. Fai gli esercizi e controlla quali concetti usano.
5. Quando aggiungi materiale nuovo, crea una nota concetto breve e inseriscila nella mappa corretta.

## Regola anti-caos
Crea una nuova nota solo quando il concetto può diventare una domanda d'esame, una legge, una formula, un esercizio o un collegamento importante.
